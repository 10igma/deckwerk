Erste veröffentlichte Fassung von Deckwerk, einer freien Desktop-DJ-Software für Techno (GPL-3.0).

> **English:** First public release of Deckwerk, a free, open-source desktop DJ application for techno: track analysis (tempo, beat grid, key, loudness), two beat-synced decks with EQ, filter and crossfader, drawable transitions with preview, and master recording. This is an early version; the installers are unsigned and have not yet been tested by hand. The interface is available in German and English.

## Was drin ist

- **Dateien lesen:** MP3, WAV, AIFF, FLAC, AAC/M4A, ALAC, OGG Vorbis, Opus
- **Analyse** im Hintergrund: Tempo, Beat-Raster, Downbeat, Tonart, Lautheit, Wellenform
- **Mixen:** zwei Decks mit Beat-Sync, 3-Band-EQ mit Kills, Filter, Kanalfader, Crossfader, Limiter
- **Wellenformen** an gemeinsamer Beat-Schiene, Zoom bis 128 Beats, Vorausblick
- **Übergänge:** Vorlagen per Taste live abspielen; Editor zum Zeichnen eigener Reglerverläufe, Vorhören, Speichern je Paar von Tracks
- **Bibliothek:** Import durch Ablegen, Suche, Filter „Passend", Aktualisieren der Musikordner
- **Mitschnitt** des Master-Signals als WAV (24 bit)
- **Kommandozeile** `deckwerk`: analysieren, Übergänge rendern, Analyse gegen Referenzwerte prüfen

## Installieren

| System | Datei |
|---|---|
| Windows | `.msi` oder `-setup.exe` |
| macOS (Apple Silicon) | `.dmg` |
| Linux | `.deb`, `.rpm` oder `.AppImage` |

Die Installer sind nicht signiert: Windows zeigt eine SmartScreen-Warnung („Weitere Informationen" → „Trotzdem ausführen"), macOS verlangt das Öffnen über das Kontextmenü oder die Freigabe unter „Datenschutz & Sicherheit".

## Was du wissen solltest

- Die Installer stammen aus der Build-Pipeline und wurden noch nicht von Hand installiert und gestartet. Geprüft ist die Anwendung bisher aus den Quellen gebaut, unter Windows, macOS und Linux.
- Ton wurde unter Windows (WASAPI) und macOS (CoreAudio) am eingebauten Ausgabegerät gehört. Externe Interfaces, Kopfhörer-Weg, ASIO und die Ausgabe unter Linux sind ungeprüft.
- Die Analyse trifft Tempo und Tonart im üblichen Techno-Bereich zuverlässig; unter 110 BPM kommt halbes oder doppeltes Tempo vor, und Dur und Moll werden gelegentlich verwechselt.
- Editor, Vorhören und Übergänge je Paar sind in den Rechenregeln getestet, in der laufenden Anwendung aber erst teilweise ausprobiert.
- Es fehlen noch: Key Lock (Tempoänderung ändert die Tonhöhe), Loops, Hotcues, Effekte, Auto-Mix für ganze Sets, Stems.
